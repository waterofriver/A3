# 知识库搭建指南

> 本文档写给负责知识库搭建的同学。读完这篇，你就知道该怎样把"机器人与安全"课程的 Word/PPT/PDF/视频，整理成程序能直接读取的知识库。

---

## 一、你要交付的最终产物

一共两样东西：

| 产物 | 文件名 | 说明 |
|------|--------|------|
| 知识点 DAG | `knowledge_base/knowledge_dag.json` | 这门课的知识体系骨架，所有 Agent 靠它决定"先教什么、后教什么" |
| 素材文件 | `knowledge_base/materials/` | 每个知识点对应的 Word、PPT、PDF、视频等原始资料 |

## 二、核心概念：什么是"知识点 DAG"

**DAG = 有向无环图。** 说白了就是一张"先修关系表"——学 B 之前必须先学 A。

举个例子，如果课程是"数据结构"：

```
数组  ──→  链表  ──→  栈
                ──→  队列
                ──→  二叉树  ──→  堆
                          ──→  二叉搜索树
```

每一行是一个**知识点节点**。箭头表示"前置依赖"：学"链表"必须先会"数组"，学"二叉树"必须先会"链表"。

**你要做的就是把"机器人与安全"拆成这样一颗颗知识点，标清楚谁依赖谁。**

## 三、怎样拆解知识点（分三步走）

### 第 1 步：列出所有知识点

翻一遍你手上的教材、PPT、大纲，把所有重要的知识点列出来。颗粒度建议：**一个知识点约等于一节课的内容**（30-60 分钟能学完）。

比如"机器人与安全"可能会拆出：

- 机器人运动学基础
- 机器人动力学
- 传感器原理与分类
- 机器人控制系统架构
- 工业机器人安全标准
- 协作机器人安全设计
- 机器人通信安全
- 视觉感知与安全避障

### 第 2 步：标注依赖关系

对每个知识点问一个问题：**学它之前，必须先会什么？**

- 学"机器人动力学" → 必须先会"机器人运动学基础"
- 学"协作机器人安全设计" → 必须先会"工业机器人安全标准" + "传感器原理"
- 学"视觉感知与安全避障" → 必须先会"传感器原理" + "机器人控制系统架构"

### 第 3 步：给每个知识点标参数

| 参数 | 说明 | 示例 |
|------|------|------|
| 难度 | 1-5，1=入门概念，5=高阶推导 | "机器人运动学基础"→2，"动力学建模"→4 |
| 建议学习时长 | 分钟 | "传感器原理"→45min |
| 分类/章节 | 属于哪个大模块 | "感知系统"、"安全规范" |
| 标签 | 便于检索的关键词 | ["运动学", "DH参数", "坐标变换"] |

## 四、JSON 模板怎么填

打开 `knowledge_dag_template.json`，模板里有一条占位示例，你删掉它，然后按同样格式逐个填入你的真实知识点。

### 每个知识点的字段说明

```json
{
  "id": "knowledge_point_01",         // 唯一ID，用英文+下划线，不能重复
  "name": "知识点名称",                // 中文名称，前端会显示
  "description": "用 1-2 句话简述该知识点涵盖的内容",
  "category": "所属大模块 / 章节名",    // 用于分类
  "prerequisites": [],                // 前置知识点ID列表，空数组=没有前置（入口知识点）
  "difficulty": 1,                    // 难度 1-5
  "estimated_minutes": 30,            // 建议学习时长（分钟）
  "tags": ["标签1", "标签2", "标签3"]    // 检索标签
}
```

### 填写的关键规则

1. **每个知识点的 `id` 不能重复**，建议用英文缩写：`security_basics`、`risk_assessment`、`auth_protocol`
2. **`prerequisites` 里填的是其他知识点的 `id`**，不是名称。比如 `"prerequisites": ["security_basics", "network_fundamentals"]`
3. **至少要有 1 个入口知识点**（`prerequisites` 为空数组的那个），否则 Planner 没法规划路径
4. **知识点数量建议 15-30 个**，太少路径没意义，太多拆分过细

## 五、素材文件怎么放

目录结构如下：

```
knowledge_base/
└── materials/
    ├── security_basics/              ← 文件夹名 = 知识点 ID
    │   ├── 安全导论课件.pptx
    │   ├── 安全基础讲义.pdf
    │   └── 安全概述视频.mp4
    ├── risk_assessment/
    │   ├── 风险评估方法.pdf
    │   ├── 评估案例.docx
    │   └── ...
    └── auth_protocol/
        ├── 认证协议原理.pdf
        └── ...
```

规则很简单：

1. **以知识点 ID 命名文件夹**（和 JSON 里的 `id` 保持一致）
2. **把所有相关素材扔进去**，文件名叫什么无所谓（中文英文都行）
3. **支持的格式**：`.docx`、`.pptx`、`.pdf`、`.mp4`、`.png/.jpg`、`.txt/.md`

## 七、常见问题

**Q: 一个知识点依赖多个前置，怎么写？**
A: `prerequisites` 是个数组，直接列就行：`["math_basics", "security_fundamentals"]`

**Q: 循环依赖是什么意思？**
A: 比如"运动学"的前置写了"动力学"，"动力学"的前置又写了"运动学"——这就死循环了。如果确实需要交替讲解，拆成两个子节点：动力学(上)和动力学(下)。

**Q: 难度怎么定？**
A: 参考标准：1=高中生能懂的概念介绍；2=本科生通识课水平；3=专业核心课；4=研究生课程/高阶推导；5=需要大量数理背景的前沿专题。

**Q: 我的 JSON 格式写对了没有？**
A: 填完后运行 `python validate_knowledge_base.py`，它会自动检查所有格式错误并告诉你第几行有问题。
