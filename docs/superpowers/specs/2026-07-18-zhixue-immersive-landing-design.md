# 智学引擎沉浸式展示登录页设计规格

## 目标

将现有 `/login` 的静态双栏登录页升级为智学引擎的沉浸式品牌展示页，同时保留既有 `user_id` 登录、用户状态查询和新老用户分流行为。

页面以连续的 Three.js 学习智能中枢为视觉主线：首屏建立品牌印象，向下滚动依次叙述学习画像、智能资源、成长路径、评估与记忆四项平台能力。页面不出现 ROS、机器人、网络安全实验或任何具体课程课件内容。

## 体验原则

- 视觉语言：高级、简约、暗色、克制。使用黑色和极深蓝作为底色，冷蓝、低饱和紫和少量暖白作为状态强调。
- 内容语言：面向学习成长闭环，避免具体学科、课程、硬件或实验场景。
- 场景语言：同一 Three.js 中枢随滚动改变叙事状态，避免首屏三维、后续普通静态卡片之间的割裂。
- 交互语言：鼠标只触发轻量视差、粒子偏移与重点节点亮起，不提供拖拽旋转等影响阅读的复杂操控。
- 兼容性：桌面端获得完整 WebGL 效果；移动端、低性能设备和不支持 WebGL 的环境必须获得可读、可登录的简化版本。

## 信息架构

页面由固定顶栏、连续场景画布、五段滚动章节和按需出现的登录浮层构成。

| 区域 | 内容 | 行为 |
| --- | --- | --- |
| 固定顶栏 | 品牌标识、四个章节锚点、`进入学习空间` | 锚点平滑滚动；入口打开登录浮层 |
| Three.js 场景 | 粒子、节点、连线、轨道、弱透视网格 | 固定于视口背景，按照滚动进度更新叙事状态 |
| 首屏 | `智学引擎`、`从学习数据到个性化成长路径`、少量能力关键词 | 建立品牌与视觉焦点 |
| 学习画像 | 对学习目标、基础、偏好和状态的理解 | 对应场景形成个人节点簇 |
| 智能资源 | 围绕当前需要组织学习内容 | 对应场景展开为资源网络与信息流 |
| 成长路径 | 将目标拆为阶段和下一步行动 | 对应场景将连线聚为有方向的流动路径 |
| 评估与记忆 | 识别薄弱点并形成复习节奏 | 对应场景转为稳定、呼吸式的记忆节点网络 |
| 登录浮层 | 现有用户 ID 输入、错误提示、提交状态 | 打开时压暗背景；关闭后返回当前滚动位置 |

## 页面状态

### 章节状态

滚动进度映射为五个离散章节锚点，并在相邻锚点间插值。每一段都保留标题、正文和章节序号，不能只依赖 Canvas 承载信息。

1. `intro`：粒子由外围缓慢向右侧核心聚集，显示完整的智能中枢。
2. `profile`：核心中出现少量高亮节点簇与细密连线，强调“理解学习者”。
3. `resources`：节点向外扩展为有序网络，沿连线出现缓慢流动的资源信号。
4. `path`：大部分连线收束为具有前进方向的曲线和轨迹。
5. `memory`：场景密度降低，关键节点依照缓慢节奏明暗呼吸，形成总结感。

### 登录状态

- 初始：登录表单不显示。
- 打开：点击顶栏或首屏的 `进入学习空间`，浮层淡入并获得输入焦点；画布亮度降低且保留低频动画。
- 提交：复用 `apiFetch` 请求 `/api/user/info?user_id=...`、`setUserId` 和现有分流规则。提交中禁止重复提交。
- 成功：画像未确认跳转 `/profile`，已确认跳转 `/workspace`。
- 失败：在表单内显示现有错误契约的可读文案，不关闭浮层。
- 关闭：点击关闭控件、遮罩或 `Escape`，返回展示页，不清空页面滚动进度。

## 组件边界

| 组件 | 职责 | 依赖 |
| --- | --- | --- |
| `ImmersiveLoginPage` | 组织页面、章节、顶栏和浮层状态 | 登录逻辑、滚动状态 |
| `LearningCoreScene` | 管理 Three.js 渲染器、粒子、线条、节点、场景状态与销毁 | Three.js、场景配置 |
| `LandingChapter` | 渲染单一章节的语义内容和进入动画 | 章节文案、可见性状态 |
| `LandingNavigation` | 品牌、章节锚点与登录入口 | 当前章节、打开回调 |
| `LoginOverlay` | 展示并承载已有登录表单逻辑 | 现有 session/API 工具、关闭回调 |
| `SceneFallback` | WebGL 不可用或用户偏好减少动态效果时的 CSS 深色网格/光点背景 | 无 |

现有 `LoginPanel` 的会话和路由逻辑应抽出为可复用表单单元，避免复制 API 调用。浮层容器负责动画、焦点管理和关闭行为；表单单元只负责输入、校验、提交和错误状态。

## 技术设计

- 引入 `three` 作为直接渲染依赖；使用 React 生命周期管理 canvas，不将高频帧状态写入 React state。
- 场景使用固定定位画布，正文保持正常文档流，以语义 HTML 支持可访问性与无 WebGL 阅读。
- 使用 `requestAnimationFrame` 渲染；当标签页不可见时暂停或显著降帧。
- 场景配置按章节定义粒子密度、核心半径、线条强度、色彩与相机目标，滚动时使用缓动插值。
- 鼠标输入经节流与插值后影响相机偏移和少量粒子扰动；`pointer: coarse` 时关闭这项互动。
- 使用 `prefers-reduced-motion`：停止自动旋转与粒子漂移，章节变化只保留即时或极短淡入。
- 通过媒体查询和性能预算降低移动端粒子数、连线数量、设备像素比与动画频率。
- Canvas 初始化、WebGL 上下文丢失和组件卸载必须销毁几何体、材质、纹理、渲染器及事件监听，避免路由往返泄漏。

## 文案范围

允许使用：`学习画像`、`智能资源`、`成长路径`、`评估与记忆`、`知识图谱`、`学习数据`、`个性化成长`、`学习空间`。

禁止使用：具体课程名、ROS、机器人、硬件、网络攻防、实验操作及其图标或示意。

## 失败与降级

- Three.js 加载、初始化或渲染失败时，保留全部正文、导航、登录入口与登录浮层，场景替换为 `SceneFallback`。
- 用户浏览器禁用 WebGL 时不显示错误弹窗，不阻碍访问登录入口。
- 动画资源加载期间显示稳定的深色背景和正文，不展示空白画布或跳动布局。
- API 故障沿用现有表单错误展示，不将其作为全页错误处理。

## 验收标准

- `/login` 在桌面端具有完整深色 Three.js 学习中枢，首屏构图与给定参考图同类但不复制具体元素。
- 页面滚动可依次浏览五段内容，四个功能页分别准确覆盖学习画像、智能资源、成长路径、评估与记忆。
- 页面与文案不含 ROS、机器人、课件、实验或其他具体课程信息。
- 鼠标在桌面端带来细微场景反馈，且不会影响滚动、选中文本、导航或登录操作。
- 点击 `进入学习空间` 后浮现可关闭的登录面板；原有 API 查询、`user_id` 保存和 `/profile`/`/workspace` 分流通过回归测试。
- 1366x768、1920x1080 与 440x900 下无明显溢出、文本遮挡或控件重叠。
- 在移动端、`prefers-reduced-motion` 和 WebGL 不可用场景下，正文与登录功能完整可用。
- 类型检查、现有登录组件测试和新增展示页交互测试通过；以浏览器截图检查桌面与移动端画面非空、场景可见且章节文案可读。
