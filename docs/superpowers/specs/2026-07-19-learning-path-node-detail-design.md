# 学习路径节点详情设计

## 目标

提高学习路径节点与画布的可读性，恢复标题为节点主内容，并将节点状态操作从直接点击改为详情浮层中的单按钮双向切换。

## 视觉与布局

学习路径仍由 React Flow 渲染，节点按 `position` 排序并顺序连线。坐标采用固定的交错偏移序列，而不是规则行列网格；因此阅读方向和先后顺序不变，同时保留路径的流动感。

节点卡片显示阶段标题、难度和简洁状态，标题最多两行。画布使用较深的点阵、白色节点背景、可辨别的描边和阴影；完成节点使用高对比度绿色状态，未完成节点使用蓝灰色状态。建议文本不再出现在卡片内。

## 交互与数据流

点击任意节点打开小型详情浮层。浮层显示完整标题、难度、建议、绑定资源提示和当前状态；有绑定资源时提供打开资源的链接。浮层只包含一个状态按钮：未完成节点显示“未完成”，点击后标记完成；已完成节点显示“已完成”，点击后重置为未完成。操作成功后关闭浮层并刷新路径数据。

前端向现有 `/api/learning/events` 发送 `path_node_completed` 或新增的 `path_node_reset` 事件。后端为新事件清除对应学习路径节点的 `completed_at`，返回后由前端失效学习路径查询缓存。

## 错误处理与验证

缺少用户或课程上下文时不发出事件。事件请求失败时保留浮层和当前界面状态，避免制造虚假的完成状态。组件测试覆盖详情显示、状态按钮标签与回调、资源入口、交错坐标和顺序连线。后端测试覆盖完成后重置节点的持久化效果。
