# 智学引擎答辩演示脚本

目标时长 7-9 分钟。演示以 `AGENT_MODE=mock` 验证平台框架；开场明确说明真实 Agent、正式课程文件和真实媒体 URL 是队友后续接入项。不要把缺失素材描述成已经生成。

## 演示前准备

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

记录脚本打印的 Web/API 地址。浏览器使用 1440x900，缩放 100%。准备一个新用户 `demo-20260711`；如需展示知识库真实内容，提前放入经授权的课程文件并重启 API，否则保留真实空状态。

## 1. 登录与系统框架（约 40 秒）

打开 `/login`：

- 输入 `demo-20260711` 并登录。
- 说明前端只在本地保存简易 `user_id`，画像和学习数据由 SQLite 持久化。
- 指出新用户自动进入 `/profile`，老用户会进入 `/workspace`。

## 2. 流式画像采集（约 70 秒）

在 `/profile` 输入：

> 我正在学习 ROS2，Python 基础一般，发布订阅和 QoS 比较薄弱，喜欢先看图再做代码，希望两周完成一个通信小项目。

演示要点：

- 左侧回答逐段出现，不等待整段完成。
- 顶部进度和当前“画像抽取Agent”实时变化。
- 右侧六维画像增量刷新，字段固定且由后端返回。
- 点击“确认画像”，进入资源工作台。

## 3. 多资源生成工作台（约 100 秒）

在 `/workspace`：

- 选择课程，薄弱点填写“发布订阅与 QoS”。
- 选择讲义、思维导图、题库、代码和图文视频五类资源。
- 点击生成，展示全局进度、当前 Agent 和每类独立进度。
- 强调任务先返回 `task_id`，页面随后订阅持久化 SSE，断线可按序号恢复。
- 完成后展示 Markdown、图谱、题库和代码卡片。
- 视频卡片显示“等待真实 Agent 返回素材”；这是刻意的真实状态，本地没有伪造 MP4。

## 4. 资源学习与答题（约 70 秒）

打开一个 `/resources/{resourceId}` 详情：

- 展示 Markdown 表格/代码块或代码复制。
- 进入题库，完成选择、填空或编程题并提交。
- 展示逐题反馈与分数，说明结果写回后端学习记录。
- 回到工作台，说明已成功卡片不会因其他类型失败而消失。

## 5. 学习路径（约 50 秒）

打开 `/path`：

- 顶部复述六维画像摘要。
- 展示“基础补全 → 知识点学习 → 习题训练 → 代码实操 → 拓展视频”五阶段路线。
- 点击绑定资源节点进入相应资料。
- 说明路线由后端 Agent/Mock Provider 规划，前端只做可视化。

## 6. 全局智能答疑（约 70 秒）

从任意页面打开 `QaDrawer`：

- 选择文字模式，询问“ROS2 QoS 的可靠性策略如何选择？”
- 展示画像感知的流式文字回答。
- 再选择图解或短视频模式，说明 `media.ready` 与文字流分离。
- Mock 下媒体 URL 为 `null`，卡片明确等待真实 Agent；接入后无需改页面结构。

## 7. 学习评估与计划更新（约 60 秒）

打开 `/evaluation`：

- 展示理论掌握度、实操能力、薄弱点频次和调整建议。
- 点击一键更新计划。
- 说明相同报告重复点击是幂等操作，不会反复创建路径版本。
- 返回 `/path` 查看新版本。

## 8. 课程知识库（约 40 秒）

打开 `/knowledge`：

- 有真实文件时展示章节树、文件元数据和只读预览。
- 没有真实文件时展示“课程资料未同步”，并说明系统不生成虚构教材。
- 指出支持 Markdown、PDF、DOCX、PPTX 文本层，原文件由受路径保护的媒体路由打开。

## 9. 学习记忆助手（约 60 秒）

打开 `/memory`：

- 展示“总体记忆健康分”和选中知识点的第 0、1、3、7 天预计记忆保持度曲线。
- 指出这是结合测验、学习行为、路径完成状态和课程知识图谱得出的复习顺序估计，不宣称为心理测量结果。
- 选择一个“优先复习”知识点，展示“先补什么”中的前置知识定位及其原因。
- 展示不超过三条的“今日复习建议”，强调短时微任务而不是泛化提醒。
- 新用户场景下，展示“课程起步建议”标记，说明系统会在有真实学习行为后更新为个人估计。

## 10. 架构收尾（约 40 秒）

展示 `/docs` 或接口说明：

- 前端只对接固定 FastAPI JSON/SSE 契约。
- `AGENT_MODE=remote` 后由 Remote Provider 调用队友的画像、资源、答疑、路径和评估端点。
- 远程错误默认直接呈现；只有显式允许时才降级，并标记 `demo_mode=true`。
- 论坛与 Coze 已从活动产品删除，旧 Django 不参与部署。

## 异常备用路径

- 页面失去网络：保留缓存内容，展示离线横幅；恢复后重试。
- 单个资源 Agent 失败：展示该类型错误和重试，保留其他成功资源。
- 远程 Agent 不可用：切回 `AGENT_MODE=mock` 只演示框架，明确说明数据为演示模式。
- 正式课程缺失：展示 `/knowledge` 的真实空状态，不临时加入虚构材料。
- 图片或视频缺失：保留无素材卡片，不生成本地 PNG/MP4 代替。

演示结束后按 `Ctrl+C` 停止本地服务，并保留 `artifacts/screenshots/`、测试输出和本窗口对话总结作为交付证据。
