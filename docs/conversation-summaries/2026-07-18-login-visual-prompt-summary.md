# 2026-07-18 登录展示页视觉提示词对话总结

## 用户目标

浏览本地运行的智学引擎网站，为登录展示页生成一条能够体现产品特色的图像生成提示词。生成的视觉稿将作为后续重写登录页前端的参考。

## 已核对的产品事实

- 产品名称：智学引擎（Zhixue Engine），定位为多智能体个性化学习系统。
- 登录页当前采用深色品牌展示区与浅色登录表单区的双栏布局。
- 核心业务闭环包括学生画像、资源生成、学习路径、学习答疑、学习评估与记忆保持。
- 课程内容具有明确领域特色：ROS/机器人实验，以及网络安全实验。
- 视觉稿应把机器人移动、ROS 节点通信、知识图谱和安全网络拓扑融合为一个可读的教学实验场景，避免泛化为办公型 AI、金融仪表盘或普通慕课网站。

## 本地运行状态

- `http://127.0.0.1:3000/login` 返回 HTTP 200。
- `http://127.0.0.1:3001/login` 返回 HTTP 200。
- 自动化浏览器因系统未安装 Playwright 所需的 Chrome/Chromium 发行版而无法启动；已结合当前组件实现、现有登录截图和项目文档完成页面分析。

## 交付内容

向用户提供一条适合生成登录展示页参考图的中文主提示词、一条负面提示词，以及用于后续前端重写的构图要点。

## 用户补充偏好

- 用户提供了参考图，希望登录展示页更接近深色、克制、未来感的产品展示主页：左侧大标题与价值表达，右侧以抽象系统图形承载核心能力。
- 用户希望新的提示词保持宽松，只覆盖产品功能与视觉关键词，给生图模型留出构图和表现空间；不需要限定页面比例、具体控件位置或严格的界面实现规则。

## 展示页改造结论

- 用户要求将 `/login` 从静态登录卡片升级为沉浸式品牌展示页，并指定使用 Three.js。
- 视觉方向：高级、简约、黑暗，以线条、粒子、节点网络和弱网格表现抽象学习智能中枢；不出现 ROS、机器人或其他具体课件信息。
- 交互方向：鼠标提供轻微视差、粒子扰动和节点高亮；登录改为点击入口后出现的可关闭悬浮层。
- 内容方向：向下滚动呈现四个功能主题，分别是学习画像、智能资源、成长路径、评估与记忆。
- 已确认采用方案 A：一套连续的 Three.js 场景由滚动驱动，从首屏到四个功能章节逐步变形，而非首屏三维加后续静态页面。
- 用户确认了完整的页面与交互设计，下一步是写入设计规格并等待用户审阅后再进入实现计划。
