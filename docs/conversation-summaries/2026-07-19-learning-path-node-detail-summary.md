# 学习路径节点详情对话总结

## 用户目标

改进学习路径模块：提高节点与背景的对比度，消除文字遮挡，恢复节点标题为卡片主内容；点击节点时显示包含标题和建议等详细信息的浮层，并提供“标记已完成”和“重置为未完成”两个操作；保留学习路径原有的非规则顺序布局。

## 当前状态

已确认相关前端实现位于 `Course-Agent/creative`，且工作区已有未提交的相关改动。用户选择不启用浏览器草图，确认详情浮层方案，并要求单一状态按钮显示当前状态文字“未完成”或“已完成”；点击后切换状态并自动关闭浮层。

## 已实现

- 学习路径节点改为高对比度标题卡片，并使用顺序驱动的交错坐标，保留连线顺序。

- 前后端新增 `path_node_reset` 学习事件，用于清除节点完成时间。
- 新增或更新前后端测试；后端事件测试 3 项通过，前端学习路径测试 7 项通过，前端类型检查和改动文件的定向 ESLint 通过。
